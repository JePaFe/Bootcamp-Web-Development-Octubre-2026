# Libros en ronda

## Descripción

Sitio web para un encuentro de intercambio de libros. Permite consultar información del evento, conocer los horarios y completar un formulario de reserva.

## Páginas y funcionalidades

- **Inicio:** información del evento y pasos para participar.
- **Horarios:** tabla con los turnos disponibles.
- **Reserva:** formulario para elegir un turno e ingresar los datos solicitados.
- **Navegación:** enlaces entre las páginas del sitio.

## Tecnologías utilizadas

- HTML5

## Cómo utilizar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir el archivo `index.html` en un navegador.
3. Navegar por las páginas y probar el formulario.

**Importante:** el formulario es una demostración. No almacena ni envía reservas reales.
